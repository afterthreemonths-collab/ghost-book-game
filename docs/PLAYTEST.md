# 当前试玩说明

## 当前状态

项目已经具备一个可在微信小游戏工程中运行的首个垂直切片：

- 题材：宫斗本
- 形态：Canvas 2D 微信小游戏
- 入口：`game.js`
- 内容：从入宫到终局的完整单册流程

## 在微信开发者工具中打开

1. 打开微信开发者工具
2. 选择“小游戏”
3. 导入当前目录：`/Users/xwx/MyProjects/ghost-book-game`
4. 使用已有 `project.config.json` 和 `game.json`
5. 直接预览运行

## 当前体验范围

- 可点击选择推进剧情
- 不同前史会改变后文文本和部分选项
- 存在概率分支
- 可以走到多种结局
- 支持结算页和重新开始

## 本地校验命令

在终端里可先跑：

```bash
node scripts/verify-book.js
```

该脚本目前会检查：

- 跳转目标是否存在
- 非终局节点是否存在可选项
- 是否存在不可达节点
- 500 次随机模拟是否有异常断链

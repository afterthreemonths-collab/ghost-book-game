# Palace Theme Rules

本文件记录宫斗题材专用规则。

## 初始规则

- 宫斗冲突来源要多样，不只靠陷害，也要有礼制、站队、资源交换、误判
- 高调行为必须同时提高收益与风险
- 低调路线必须给予情报、避险或后手收益
- 宫女、太监、嬷嬷等边缘人物承担情报与转折功能
- 得宠不是唯一高价值目标，识局、借势、逃离都应是有效回报
- 贵妃、皇后、皇帝等关键角色应体现不同类型的压力，不要功能重复
- 结局价值不能单一以上位为尊，逃离和生存线也应成立
- 宫斗题材里高调路线必须同时提高宠爱和风声，不可只给正反馈
- 逃离线必须提前铺垫，不能等终局才临时给出
- 保下边缘人物后，后文至少要在一次关键节点和一次结局中体现其价值
- 皇后线、皇子线、逃离线都需要各自的保底结局，避免玩家走到终点却没有归属

## 后续维护方式

当某次宫斗本扩写暴露出题材问题时，把规则沉淀到这里。

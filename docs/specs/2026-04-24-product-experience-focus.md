# Product Experience Focus

## Goal

This document records the current high-priority product experience goals that should shape future story, interaction, and presentation work.

## Core Priorities

### 1. Positive Feedback

Players should repeatedly feel:

- their choices mattered
- they gained leverage, insight, favor, or survival advantage
- they are becoming sharper, safer, or more powerful

Positive feedback should not only come from numbers.

It should also come from:

- story callbacks
- new options
- new information
- visible shifts in how others treat the player

### 2. Payoff / “爽点”

The project needs strong payoff moments, not only steady narrative flow.

Target payoff types include:

- getting noticed at the right time
- seeing through a trap
- turning a disadvantage into leverage
- quietly winning a social exchange
- preserving a hidden retreat path
- escaping with style

### 3. Share Desire

After a run, the player should feel:

- this ending says something about the run
- this result is worth showing someone
- the route they got feels distinctive

Share desire should come from:

- clear ending names
- route identity
- emotionally sharp result text
- rare or high-value outcomes
- score plus story meaning together

### 4. Share Image / Share Card

The future result-sharing asset should be treated as a product feature, not a decorative extra.

It should eventually include:

- strong title
- ending name
- route tags
- score and grade
- one strong quote or summary line
- clear visual style

### 5. Character / Event Illustration During Play

We should explore adding visual illustration during the story flow.

Possible uses:

- key character image moments
- event splash scenes
- emotional high points
- key turning points before choices

The purpose is to improve:

- memory
- immersion
- emotional payoff
- future reuse for sharing assets

## Design Rule

Future discussions and changes should evaluate work not only by:

- whether the story logic works
- whether the branch is valid

but also by:

- whether the player feels rewarded
- whether the run creates memorable payoff
- whether the result feels shareable
- whether the visual layer can support those goals

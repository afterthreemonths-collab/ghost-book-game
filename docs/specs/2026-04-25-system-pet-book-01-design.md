# 伴生灵宠·系统流首册设计方案

## 一、世界观设定

- **世界**：灵兽纪元。人类到 16 岁可由学校统一激发"伴生灵宠"，灵宠品质决定修炼上限。
- **主角**：普通高中生，觉醒仪式上激活了一只"品质极低"的伴生灵宠——**小熊猫**。
- **系统**：同时激活了"神级选择系统"，遇到冲突/嘲讽/抉择/危险场景时自动弹出 A/B/C 三选一。
- **核心爽点**：全世界都认为小熊猫是废物，但系统奖励让它走上反常识天花板路线。

## 二、灵宠设定：小熊猫

### 初始形态（零阶）
- 名称：小熊猫（可自定义）
- 外观：毛茸茸、红棕色、大尾巴、看着人畜无害
- 品质判定：极差（校方检测为 F 级）
- 属性：全属性极低
- 能力：卖萌、吃竹子、爬树

### 进化路线
- **一阶进化**：待定（反差形态，比如"暴食熊猫"或"战熊形态"）
- **二阶进化**：完全体（碾压级存在）

### 成长系统
- 属性：力量、防御、速度、灵力、生命
- 天赋：被动能力（物理免疫、自愈、元素抗性等）
- 技能：主动能力（吨位碾压、禁咒吐息等）
- 体型：small → medium → large → giant
- 进化阶段：0 → 1 → 2

## 三、系统机制

### 触发条件
场景 `mode` 标记为 `system_choice`，到达时自动触发系统三选一。

### 选项梯度
| 选项 | 风险 | 奖励 | 剧情影响 |
|------|------|------|----------|
| A | 低（安全） | 蚊子腿 | 剧情保守推进 |
| B | 中 | 中等 | 剧情正常推进 |
| C | 高（可能翻车） | 逆天 | 剧情激进推进，可能进入战斗/冲突 |

### 奖励类型
- 属性加成（pet.attributes 变化）
- 天赋解锁（pet.talents 添加）
- 技能解锁（pet.skills 添加）
- 体型变化（pet.size 变化）
- 进化碎片（积累到一定数量触发进化事件）
- 金币/道具

## 四、剧情节奏（前期发育阶段，约 18 个场景）

### 第一章：觉醒（场景 1-4）
1. **觉醒仪式**：同学纷纷觉醒强力灵宠，主角激活小熊猫，被全校嘲笑
2. **系统初现**：第一次系统选择（同学嘲讽）→ 决定初始天赋
3. **课堂冲突**：老师贬低小熊猫 → 第二次系统选择
4. **被孤立**：日常被嘲笑，但系统提示小熊猫在悄悄变化

### 第二章：初露锋芒（场景 5-9）
5. **野外试炼**：学校组织，遭遇低阶灵兽
6. **遭遇冲突**：系统选择（是否让小熊猫出手）
7. **初战**：如果选了硬刚，小熊猫展现惊人实力
8. **资源争夺**：遭遇恶霸抢野外宝箱 → 系统选择
9. **首次奖励结算**：获得第一个关键天赋

### 第三章：校内打脸（场景 10-14）
10. **校内考核**：老师组织实力测试
11. **天才挑衅**：世家子弟/天才嘲讽 → 系统选择
12. **碾压**：小熊猫碾压对手，全场震惊
13. **质疑**：老师/校方质疑作弊 → 系统选择
14. **证明实力**：实战演示，打破质疑

### 第四章：进化前夜（场景 15-18）
15. **积累碎片**：进化碎片达标，触发进化事件
16. **进化选择**：系统选择决定进化方向
17. **一阶进化**：形态变化，属性暴涨
18. **进化首秀**：新形态展现实力，阶段性高潮

## 五、爽感设计

1. **反差萌**：可爱小熊猫 vs 逆天战力，每次出手都有"这怎么可能"的震惊感
2. **信息差策略**：玩家知道选 C 奖励好但可能翻车，需要判断当前状态是否扛得住
3. **可视化成长**：每次选择后属性数字跳动，天赋一个个点亮
4. **打脸循环**：嘲讽 → 选择 → 变强 → 碾压 → 震惊 → 新一轮嘲讽
5. **进化爽点**：积累 → 质变 → 首秀，经典的"脱胎换骨"正反馈

## 六、UI 设计

### 系统选项 vs 普通选项区分
- **系统场景标题**：带 【系统任务】标记
- **系统选项按钮**：
  - 金色边框 + 微发光效果
  - 选项前带 A/B/C 标记
  - 选项下方显示预估风险等级（🛡️安全 / ⚠️危险 / 🔥高风险）
- **普通选项**：常规按钮样式（沿用宫斗 UI）

### 状态面板
- 入口：屏幕左上角按钮或点击小熊猫头像
- 内容：
  - 主角信息（名字、声望、金币）
  - 小熊猫信息（名字、等级、进化阶段、体型）
  - 属性面板（力量/防御/速度/灵力/生命，用进度条展示）
  - 天赋列表（已解锁 / 未解锁）
  - 技能列表

### 主界面调整
- 顶部：章节标题 + 小熊猫头像（点击打开状态面板）
- 中间：故事文本
- 底部：选项按钮
- 属性展示：用简洁 chips 展示小熊猫核心属性

## 八、实现要点

### 代码层面
1. 扩展 `schema.js`：新增 pet、player、system 状态结构
2. 扩展 `story-runner.js`：
   - 支持 pet.attributes 的数值运算
   - 支持 talents/skills 的添加逻辑
   - 支持进化碎片积累和进化触发
3. 扩展 `renderer.js`：
   - 系统选项特殊渲染（金色边框、A/B/C 标记）
   - 状态面板渲染
   - 小熊猫属性 chips
4. 新建 `js/data/books/system-pet-01.js`：首册完整数据

### 故事创作层面
1. 每个系统选择点都要设计三条不同风险梯度的选项
2. 选项 C 必须配有"高风险"描述（可能翻车）
3. 奖励要可视化，选择后立即反馈属性变化
4. 打脸场景要充分渲染"震惊感"——旁人反应要夸张

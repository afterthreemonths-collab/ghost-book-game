# Story Node Template

本文件是后续写节点时默认使用的项目模板。

## 主剧情节点模板

```text
标题：

承接层：
说明上一节点之后，事情怎么发展到这里。

临场层：
给一个具体画面、动作、表情、礼制或空间信息。

压力层：
说明这次为什么必须选，或者为什么这一步危险。

选项 A：
提示：
反馈：

选项 B：
提示：
反馈：

选项 C：
提示：
反馈：
```

## 功能节点模板

```text
标题：

短承接：
一句话说明局势变化。

当前结果：
一句话说明眼前发生了什么。

后续去向：
该节点如何把玩家送往下一个主节点。
```

## 结局模板

```text
标题：

结果落点：
玩家最后处于什么位置。

代价或余味：
这一结局的情绪重量是什么。

路线回看：
让玩家看出自己是怎么走到这里的。
```

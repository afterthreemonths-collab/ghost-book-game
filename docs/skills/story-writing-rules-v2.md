# 故事创作规则 v2（系统流题材适用）

## 一、系统与剧情的融合原则

### 1.1 不要直白告诉玩家"系统触发了"

❌ 错误：【系统任务触发】场景：被老师当众羞辱。请选择你的应对方式。
✅ 正确：剧情自然推进到冲突点，系统选项以特殊UI呈现，但叙事上保持"主角在做选择"的沉浸感。

### 1.2 系统奖励不要直接念出来

❌ 错误：系统提示：【解锁天赋：巨化之种 | 全属性暴涨】
✅ 正确：用剧情变化体现奖励——小熊猫身体涨大了一圈，水泥地被拍裂了。玩家自己感觉到"变强了"。

奖励数字可以在状态面板查看，但不要在剧情文本里播报。

### 1.3 平淡节点必须有

不是每个场景都是冲突。要有：
- 休息/恢复节点（平淡日常）
- 探索/观察节点（收集信息）
- 社交/对话节点（铺垫关系）
- 内心独白节点（塑造角色）

冲突场景和平淡节点交替，才能形成节奏。

## 二、角色塑造原则

### 2.1 嘲讽者必须有名有姓有特征

❌ 错误："同学们纷纷嘲笑"
✅ 正确："站在前排的王磊——那个觉醒出火焰狼的富二代——第一个笑出声：'就凭这只吉祥物？'"

每个重要NPC都要有：
- 名字
- 觉醒的灵宠（品质）
- 和主角的关系（为什么针对主角）
- 性格特征

### 2.2 配角是"工具人"还是"伏笔人"

每个出场的配角，要么是：
- 当前爽点的工具（被打脸的对象）
- 后续剧情的伏笔（草蛇灰线）

不要出现"围观群众"这种模糊的群体，要有具体的脸。

## 三、选项设计原则

### 3.1 选项C不一定是高风险

选项梯度应该是：
- A = 保守/怂/安全 → 小奖励
- B = 正常/中庸 → 中奖励
- C = 有趣/搞笑/玩梗/硬刚 → 最大奖励

C选项可以是：
- 硬刚打脸（高风险高回报）
- 玩梗搞笑（无风险但社死）
- 骚操作（反常识但有效）
- 装逼（可能翻车也可能超神）

不要把C选项统一写成"高风险"，那样会单调。

### 3.2 选项文案要有幽默感

示例风格：

【选项一：老实承认错误，承诺以后不会再犯。完成奖励：少量御兽力】
【选项二：双手一摊，情真意切地说道："本想以学霸的身份跟你相处，换来的却是疏远，摊牌了，我是学渣，啥也不会！" 完成奖励：下品火焰药液】
【选项三：保持沉默，低头不语。完成奖励：契约灵服从度+1】

要点：
- 选项文案本身就是"台词"，玩家在选择时就在脑补画面
- 要有反差、玩梗、 unexpected
- 不要让选项读起来像"游戏UI"，要读起来像"小说段落"

### 3.3 去掉A/B/C前缀的重复展示

❌ 错误：A. 低头忍耐 B. 简单反驳 C. 当众放话
✅ 正确：直接用不同颜色的按钮区分，选项文本不加A/B/C前缀

系统选项用金色边框标记就够了，不需要在文本里重复A/B/C。

## 四、灵宠塑造原则

### 4.1 灵宠要有"双重形态"

平时：可爱、无害、能卖萌（方便扮猪吃虎）
战时：暴涨、霸气、碾压一切（爽点爆发）

切换机制可以是系统奖励的"伪装模式"或"节能模式"。

### 4.2 灵宠要有性格

不只是"主人的工具"，要有自己的情绪反应：
- 被嘲笑时生气（毛竖起来）
- 打赢后得意（摇尾巴）
- 累了会撒娇（蹭主人）
- 关键时刻护主（挡在主人前面）

### 4.3 灵宠成长要可视化

不要只给数字，要给画面：
- 体型从巴掌大 → 足球大 → 半人高 → 卡车大
- 皮毛从柔软 → 带金属光泽 → 刀枪不入
- 眼睛从懵懂 → 锐利 → 威严
- 声音从嘤咛 → 低吼 → 震耳咆哮

## 五、节奏设计原则

### 5.1 爽点分布

- 每 3-4 个场景必须有一次"爽感释放"（打脸、变强、收获）
- 爽点前必须有"压抑"（被嘲笑、被看低、被欺负）
- 爽点要够"夸张"（反差越大越爽）

### 5.2 搞笑节点穿插

- 选项文案本身可以搞笑
- 灵宠的萌态反应可以搞笑
- 主角的内心吐槽可以搞笑
- 配角的荒诞反应可以搞笑

爽和搞笑不冲突，反而相辅相成。

### 5.3 草蛇灰线

- 早期埋下的细节，后期要有回响
- 一个看似无关的NPC，后面可能是关键助力
- 一个看似搞笑的选项，后面可能解锁隐藏路线

## 六、信息展示原则

### 6.1 状态面板不是万能的

- 觉醒前不应该有面板
- 重要信息（比如新获得的天赋）应该在剧情中体现
- 面板只是"查阅详细数据"的地方

### 6.2 战斗力要直观

不要只展示"力量 25"，要有对应的等级/评价：
- F 级 → E 级 → D 级 → C 级 → B 级 → A 级 → S 级
- 或者：菜鸟 → 入门 → 高手 → 大师 → 宗师 → 传说

让玩家一眼知道"我现在什么水平"。

## 七、创作检查清单

写完一个场景后检查：
- [ ] 嘲讽者有名字吗？
- [ ] 有平淡节点穿插吗？
- [ ] 选项C只是"高风险"吗？有搞笑/玩梗选项吗？
- [ ] 有直白系统提示语吗？
- [ ] 奖励是剧情体现还是数字播报？
- [ ] 灵宠有情绪反应吗？
- [ ] 有草蛇灰线吗？
